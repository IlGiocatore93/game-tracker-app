## Verifica il nome del branch

Su GitHub il branch principale si chiama solitamente `main`, mentre il tuo locale è `master` (l'hai visto scritto "On branch master" negli screenshot). Rinominiamolo per allinearci allo standard moderno:

```bash
git branch -M main
```

## Push finale

```bash
git push -u origin main
```

Questo carica tutto il codice sul repository GitHub. Ti potrebbe chiedere di autenticarti (username + token, non la password diretta — GitHub non accetta più password dirette da riga di comando, serve un Personal Access Token, ma se hai già configurato Git con credenziali salvate potrebbe non chiedertelo).

Prova il commit per primo, e fammi sapere l'esito prima di procedere con remote/push — un passo alla volta.

ci.yml

name: CI Pipeline

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  backend:
    name: Backend - Install & Check
    runs-on: ubuntu-latest

    steps:
      - name: Checkout codice
        uses: actions/checkout@v4

      - name: Setup Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.12'

      - name: Installa dipendenze
        working-directory: ./Backend
        run: |
          python -m pip install --upgrade pip
          pip install -r requirements.txt

      - name: Verifica import del progetto
        working-directory: ./Backend
        run: python -c "import main"

  frontend:
    name: Frontend - Build
    runs-on: ubuntu-latest

    steps:
      - name: Checkout codice
        uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: '20'

      - name: Installa dipendenze
        working-directory: ./Frontend
        run: npm ci

      - name: Build
        working-directory: ./Frontend
        run: npm run build
